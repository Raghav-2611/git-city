# 🏙️ GitCity — Your GitHub, As A City

> A playable 3D urban experience powered by React, Three.js, and your GitHub contribution history.

---

## 🚗 Features
- **3D Interactive City**: Every day in your GitHub history is mapped to a building along a central highway.
- **Dynamic Floor Heights**: 1 commit = 1 floor. High activity days spawn neon skyscrapers with rooftop helipads and crowns!
- **Playable Drive**: Control a sports car using WASD / Arrow keys to explore your commit timeline chronologically.
- **Zero Configuration**: Automatically loads public GitHub contribution data without requiring any API token.

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser!
